# WalletCore
WalletCore  WalletCore is a modern personal expense calculator and finance tracking app built with Python and Kivy.  ## Features  - 💰 Expense calculator and income tracking - 📊 Personal spending overview - 🗂️ Expense categories - 📈 Statistics and charts - 📝 Transaction history - 🌍 Multi-language support - 💾 Local SQLite database
