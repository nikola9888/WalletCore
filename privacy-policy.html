Privacy Policy - WalletCore

Last updated: July 25, 2026

Introduction

WalletCore is a personal finance application developed by DEVELOP4WORLD. This Privacy Policy explains how the application handles user data.

Data Storage

WalletCore stores financial information such as transactions, categories, and balance data locally on the user's device using local storage.

Data Collection

WalletCore does not collect, transmit, or sell personal financial data. The application does not require user registration or account creation.

Data Sharing

WalletCore does not share user data with third parties.

Deleting Data

Users can delete stored transaction data directly inside the application.
